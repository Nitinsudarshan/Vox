Yeh multi-tier vocabulary engine teen levels par operate karta hai. Sabse pehle global vocabulary layer hai, jisme hamare core institutional keywords defined hain: NavGurukul, SOSC, NGConnect, GHAR, Sama Saathi, Ares, Macquarie, Kishore, Abhishek, aur core technical stack terms like Tauri, Rust, Whisper, Supabase, whisper.cpp, aur CPAL. Second layer par meeting-specific terms dynamic prompt injection ke through supply hote hain, jo calendar events aur participant names se extract kiye jaate hain. Aur third layer par user-specific custom dictionary support hai, jisme local developers apne custom project terms save kar sakte hain.

Decoder stage par hamara context builder in terms ko intelligently inject karta hai without polluting Whisper's language prior. Model ko pata hota hai ki ye specific tokens high probability space mein hain, isliye Hindi-to-English code-switching ke dauran proper noun spellings exactly match hoti hain. Staging benchmark results show that proper noun accuracy across NavGurukul test cases jumped from fifty-eight percent to ninety-five percent, aur real-time factor par koi measurable overhead nahi aaya.

Macquarie ke data security audit ke regarding, unki compliance team ne hamare local-only architecture ko inspect kiya hai. Unka primary requirement ye tha ki meeting transcripts aur raw audio buffers kabhi bhi unauthorized cloud servers par transmit nahi hone chahiye. Since Vox stores everything inside the local vault using encrypted SQLite and local markdown files, data sovereignty completely satisfy hoti hai. Har segment ke saath hamara quality gate strict diagnostic telemetry record karta hai: start timestamp, speech duration, no-speech probability, compression ratio, aur retry count. Agar koi segment hallucination ya repeated loop exhibit karta hai, system automatically greedy recovery pass trigger karta hai.
