# Vox — Changelog

## [0.1.0] - 2026-09-11

### Initial Vox Release

- Rebranded project from Relay to Vox.
- Local-first AI voice notes and dictation pipeline powered by Whisper.
- Dynamic floating push-to-talk pill with real-time waveform and keyboard injection.
- Vault note storage, Scribble synthesis, knowledge graph, and full-text search.
- Browser companion extension for Chrome and Edge web page and AI conversation capture.
